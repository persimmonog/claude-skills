# 股票分析框架

---

## Step 0：前置分类 + 行业指标锁定

### 第一步：判断公司类型

不同类型的公司需要完全不同的分析重点和估值方法，这是整个分析的元决策。

| 类型 | 典型代表 | 分析重点 | 核心估值方法 |
|---|---|---|---|
| **平台型公司** | 美团、拼多多、Airbnb | 网络效应、DAU/MAU、抽成率、监管风险 | PS / EV/GMV |
| **品牌消费品** | 茅台、耐克、爱马仕 | 品牌溢价持久性、渠道结构、ASP趋势 | PE / DCF |
| **SaaS/订阅软件** | Salesforce、金蝶 | ARR、NRR、CAC/LTV、Rule of 40 | PS / ARR倍数 |
| **硬科技制造** | 中芯国际、ASML、宁德时代 | 研发强度、设计胜率、产能利用率、客户集中度 | PB / EV/EBITDA |
| **创新药/Biotech** | 百济神州、Moderna | 管线概率加权价值、临床风险、专利悬崖 | DCF（rNPV）|
| **强监管公用事业** | 长江电力、国家电网 | 监管框架、允许回报率、资产重置成本 | PB / 股息折现 |
| **项目制公司** | 中建国际、中国交建 | 订单储备、回款周期、应收账款质量 | PE / PB |
| **渠道品牌公司** | 安踏、泡泡玛特 | 渠道库存周转、终端动销率、IP生命周期 | PE / EV/EBIT |
| **资源/周期类** | 中国神华、紫金矿业 | 商品价格周期位置（优先于公司分析） | EV/EBITDA |
| **金融公司** | 招商银行、中国平安 | 贷款质量、NIM、资本充足率、不良率 | PB+ROE |
| **早期成长型** | 未盈利Biotech、AI新势力 | 概率加权技术/监管风险、TAM可及性 | PS / rNPV |
| **多元控股** | 伯克希尔、华润集团 | 分部估值 Sum of Parts | 各业务独立估值求和 |

> **注**：一家公司可以横跨多个类型（如小鹏兼具"硬科技制造"和"平台/技术授权"特征），此时需要对不同收入来源分别套用对应模块。

### 第二步：锁定行业指标表

分类完成后，立即建立这张表——后续所有财务分析都对照它来校验，不允许回退到通用指标。

```
行业：__________
决定胜负的核心 KPI（2-3 个）：__________
次要观测指标：__________
当前行业周期位置（景气上行/下行/底部/顶部）：__________
行业公认的合理估值区间：__________
```

## Step 1：生意本质

> 建立价值流动地图，而不是读公司介绍。

- **先画价值链路：** 一笔收入从终端用户口袋出发，经过哪些环节，每个环节被谁分走多少？列出所有参与利润分配的直接和间接对手方（供应商、IP/技术/品牌授权方、平台佣金方、渠道分销方、监管/税收方等）。步骤 2 的"定价权分析"将对照此图逐个评估。
- 这家公司靠什么赚钱？收入来源和结构是什么？
- 客户为什么选择它，而不是竞品？（具体原因，不是"产品好"）
- 成本结构：固定成本 vs 变动成本，规模越大越省钱吗？
- 收入是一次性的，还是重复发生的？（复购/订阅/消耗品，哪种模式？）
- **这门生意天然好不好？**（高毛利/强复购/轻资产 = 好生意；反之需要更高的管理要求）

---

## Step 2：行业理解

> 很多公司的命运由行业决定，而不是由管理层决定。

- **行业处于哪个生命周期阶段？** 新兴期 / 高速成长期 / 成熟期 / 衰退期——这直接影响估值逻辑
- 行业当前的周期位置：是景气上行还是下行？库存/产能处于什么状态？
- 当前这几公司核心指标的趋势方向如何？（与 Step 0 锁定的 KPI 对照）
- 定价权在谁手里？利润被哪个环节吃掉最多（供应商/渠道/客户）？
- 新进入者威胁有多大？有没有替代品在悄悄侵蚀需求？

---

## Step 3：竞争优势的真实性检验

> 区分"行业共性"和"公司特性"，是这一步最核心的任务。

- **公司声称的优势是什么？**（管理层 PPT 上写的那些）
- **这些优势是行业共性，还是公司特性？**
  → 行业顺风不是护城河；行业退潮时会原形毕露
- **如果是公司特性，为什么同行不能快速复制？**
  → 复制障碍来自：技术积累？数据飞轮？客户锁定？品牌？规模成本？牌照？
- **财务报表是否验证了这个优势？**
  → 真正的定价权体现在毛利率；真正的护城河体现在 ROIC；真正的客户粘性体现在复购率
- **这家公司最核心、最独特的待验证问题是什么？**
  → 在做投资决策之前，把最重要的未知量说清楚——这个问题没有答案，就没有足够信心建仓

---

## Step 4：财务质量

> 财报是结果，用来验证判断，不是分析的起点。用 Step 0 锁定的行业 KPI 来做主要校验，通用指标做辅助。

**① 收入质量**
- 收入来源是否集中？大客户依赖度高不高？
- 增长是真实需求驱动，还是补贴/促销/渠道压货驱动？

**② 现金流质量**
- 自由现金流 vs 账面利润，差距多大？差距越大，越需要追问原因
- 经营活动现金流能否覆盖资本支出？

**③ 资产负债表健康度**
- 债务结构和到期分布、商誉减值风险、隐性负债（经营租赁、表外负债）
- 资产负债率的趋势方向

**④ 行业 KPI 对照校验**（回填 Step 0 的指标表）
- 核心 KPI 的绝对值和趋势是否支持竞争优势判断？

---

## Step 5：股东回报与治理

> 好生意可以被差治理毁掉。这一步判断"股东是否和管理层站在同一边"。

- **管理层可信度**：历史兑现率如何？对坏消息的处理方式（解释 vs 掩盖）？
- 资本分配能力：赚来的钱怎么花？并购的历史回报如何？
- 治理结构是否保护小股东：有没有双重股权、VIE 架构、关联交易等潜在利益输送路径？
- 是否频繁融资摊薄：过去几年股本变化趋势，融资是否以牺牲现有股东为代价？
- 主要股东结构：控股股东是谁，利益取向和持仓动机是什么？有没有大股东减持信号？
- 激励机制合理性：股权激励行权条件是否与长期业绩挂钩？管理层自己是否重仓持股？

---

## Step 6：宏观与政策层

> 自下而上分析的系统性盲区——这一层可以压倒所有公司层面的判断。

- **利率敏感性**：估值和债务结构对利率变化有多敏感？
- **行业监管风险**：政府是否可能以反垄断、牌照收紧、补贴退坡重塑行业格局？
- **地缘政治 / 汇率风险**：收入/成本有多少是跨境的？供应链有没有地缘断裂风险？
- **宏观顺风还是逆风**：当前宏观周期对这个行业是助力还是阻力？
- 中概股特殊风险（如适用）：审计、退市、ADR 结构风险

---

## Step 7：估值——以"反向隐含预期"为核心

> 估值的本质不是"这家公司值多少钱"，而是**"当前价格已经要求公司做到什么程度"**。

### 核心问法（先于一切）

**当前市值要求公司在未来 3-5 年内，交付什么样的收入、利润率和现金流水平？**

把这个要求具体化，比如：
- 当前价格隐含的年化收入增速是多少？
- 隐含的稳态毛利率 / 净利率是多少？
- 隐含的 FCF 转化率是多少？
- 这些要求在历史上有没有可比公司实现过？概率有多大？

这个问题需要根据 Step 0 的公司类型，选择对应的估值方法（见分类表），不要对所有公司用同一把尺子。

### 市场分歧分析

> 预期决定价格，分歧决定收益。

- 当前市场共识是什么？
- 当前最大的争议是什么？
- 多头逻辑是什么？
- 空头逻辑是什么？

### 三情景分析

市场的悲观、基准和乐观预期，分别隐含了哪些假设？如果假设成真，股价会落在哪个区间？

| 情景 | 核心假设 | 估值逻辑 ｜ 隐含价格区间 |
|---|---|---|
| 悲观 | 关键假设落空 | | |
| 基准 | 市场共识实现 | | |
| 乐观 | 超预期兑现 | | |

### 可比公司参照

同类公司的历史估值区间是多少？当好公司被低估时，通常有什么共同特征？

## Step 8：压力测试（反向论证）

> 不要只问"为什么会成功"。把反向论证做到位，是对自己判断最诚实的检验。

- **致命假设是什么？** 我的逻辑依赖哪几个核心假设——哪个一旦证伪，整个逻辑就塌了？
- **如果我是最强的竞争对手，我会怎么打死这家公司？** 把进攻路径说具体
- **下行情景下，公司是否有足够的财务缓冲？**

---

## Step 9：持仓管理

> ⚠️ **默认不输出此步骤。** 仅当用户明确问"该不该买"、"仓位多少"、"什么时候卖"等持仓相关问题时，才输出本步。否则写到 Step 8 即结束。

> 框架的最后一步：买什么是一件事，怎么买、何时卖是另一件事。

**买入触发条件**
"看懂了"还不够。还需要：价格在安全边际内 + 有明确的正向催化剂或显著低估

**仓位逻辑**
基于确信度 × 安全边际 × 组合内相关性来决定，而不是感觉。确信度越高、安全边际越大，仓位越重。没有优势时，仓位上限不超过组合的 5%。

**持仓条件**
定期回答：当初买入的逻辑，现在还成立吗？Step 3 里的"待验证问题"是否有了新的答案？

**卖出触发条件**（预先设定，不在情绪波动时临时决策）
- 投资逻辑被证伪（不是股价下跌）
- 估值已经隐含了过于乐观的假设，赔率不再合算
- 发现了更好的机会（机会成本）
- 管理层出现重大信任问题
- 当初设定的止损线被触及

## 精简版：投资前 13 问

> 完整框架的压缩版，用于快速过滤和日常决策。

```
【分类与行业】
1. 这是什么类型的公司？对应哪套分析工具？
2. 行业决定胜负的 2-3 个核心指标是什么？
3. 行业处于什么生命周期阶段，当前周期位置在哪里？

【生意与优势】
4. 这家公司靠什么赚钱？收入是一次性的还是可重复的？
5. 客户为什么选择它而不是竞品？这门生意天然好不好？
6. 公司声称的优势是行业共性，还是公司特性？
7. 如果是公司特性，为什么同行五年内无法复制？
8. 财务报表是否验证了这个优势？
9. 这家公司最核心、最独特的待验证问题是什么？

【风险与估值】
10. 宏观、政策、地缘层面，有没有压倒公司层面判断的风险？
11. 治理结构是否保护小股东？是否存在频繁融资摊薄？
12. 当前价格要求公司未来做到什么程度？这个要求合理吗？
13. 我的致命假设是什么？什么信号说明我错了，我怎么处理？
```

---

*框架是思考的起点，不是终点。不同类型的公司需要调用不同的专属模块，没有任何框架能消除判断本身的不确定性。*
