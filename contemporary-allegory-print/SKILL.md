# 当代寓言版画 v0.3

把用户输入视为创作命题，输出最终生图 Prompt 和对应图片。严格依次执行五步：创作契约约束全程，后四步分别决定画什么、怎么画、怎么告诉模型、是否画对。

## 1. 创作契约

所有作品锁定同一公式：

> **一个可识别核心 + 一条魔法规则 + 一次可见变化 + 两色当代版画**

### 固定规则

- 竖版 3:4，棉纸或版画纸铺满画面，平视扫描或正投影视角；
- 一个主视觉关系，包含一至两个主要物体；
- 核心动作占画面 30%-60%，纸张可见面积占 30%-55%；
- 第一主墨色占 20%-45%，第二主墨色占 5%-25%；
- 一种主印刷工艺加一种辅助印刷缺陷；
- 当输入本身是完整文字命题，如句子、成语、诗句、格言或标题式表达，逐字保留原文并完整展示一次，通过字号与分行适配画面；
- 当输入不是完整文字命题时，生成一个 2-8 字短标题并只展示一次；
- 日期、编号、版次、签名和装饰性小字不进入画面；
- 平面印刷、哑光吸墨、清晰正负形和独立艺术海报完成度；
- 一秒被轮廓或色块吸引，三秒认出输入，十秒留下余味。

### 风格边界

让材料缺陷服务于形体与动作，让画面承担叙事。成品保持与商品广告、活动宣传、摄影棚摆拍、立体模型、电影剧照、多物件档案、装饰拼贴、复古民俗插画和儿童卡通之间的清晰距离。

本步输出一套全程不变的风格边界，持续约束第 2-5 步。

## 2. 语义转译

开始选择前，先判断用户输入的主体、动作、关系和情绪最适合哪一种构图、魔法规则与配色方向；适配性优先，系列轮换作为相同适配度候选之间的后置选择。

### 提取识别令牌

- 具体意象保留轮廓、动作或典型局部；
- 句子提取一个视觉名词和一个关系动词，同时把完整原文独立保存为画面展示文字；
- 抽象概念选择一个日常物质替身；
- 照片从主体、动作、重复文字、标志性色彩或空间关系中保留一个令牌，重新生成独立画面；
- 复杂主题提炼一个核心冲突或因果关系。

识别令牌在缩略图中保持清楚，在完整画面中可经历切割、放大、重复、穿越或材质转换。

把文章、说明和内容简报作为语义来源；仅在用户明确要求时全文展示。把作为独立命题提交的完整表达默认视为展示文字，保持原文、语序和标点。

当输入来自书籍、诗歌、戏剧、历史、神话、影视或其他作品的有出处引用时，先确认出处并了解原文上下文、人物关系、事件背景、情绪转折与结局，再进行语义转译；保留引用文字作为识别锚点，让视觉命题呈现它在原作中的意义。

### 选择魔法规则

- **经过即改变**：主体经过之处失去颜色、纹理、重量、文字或印刷层；
- **影子背叛**：影子呈现主体隐藏的数量、方向、愿望或后果；
- **内外互换**：容器盛放天空，身体内部出现道路，门外折回房间；
- **缺失成形**：被吃掉、擦除、遗忘或离开的部分形成第二个意象；
- **痕迹生长**：足迹继续行走，裂缝继续生长，波纹离开水面；
- **材质转译**：植物变成纸、河水变成墨、声音变成木纹；
- **尺度后果**：微小主体改变巨大色面，单一个体留下群体后果。

一次创作只使用一个规则家族和一个主要魔法动词，选择最适用于主题的魔法规则。

### 选择候选

内部构思三个 `[识别令牌 + 魔法规则 + 可见后果]` 候选，按以下权重评分：

- 输入识别度 30；
- 魔法规则可读性 25；
- 缩略图冲击力 20；
- 独立艺术作品感 15；
- 系列兼容性 10。

选择得分最高且达到 75 分的方案；不足 75 分时改写识别令牌或魔法动词再评一次。

本步输出一句视觉命题：

```text
当[识别令牌]发生[动作]时，[对象]会以不可能的方式[变化]，最终留下[可见后果]。
```

## 3. 视觉配方

只为视觉命题选择表现形式，不增加新的寓意或物体。

### 构图与规则配对

| 构图 | 视觉结构 | 适配规则 |
|---|---|---|
| crossing-field | 主体穿越巨大色域 | 经过即改变、材质转译 |
| contradictory-shadow | 主体与矛盾影子 | 影子背叛 |
| negative-devour | 空白从实体内部或边缘吞入 | 缺失成形 |
| split-threshold | 一道阈限分开变化前后 | 经过即改变、材质转译 |
| edge-arrival | 主体从画外侵入，后果占据画内 | 尺度后果 |
| scale-fable | 小主体支配巨大环境 | 尺度后果 |
| material-leak | 材质从物体内部外溢 | 内外互换、痕迹生长 |

### 材料与文字

- **锚点**：完整剪影、典型局部、动作姿态、重复文字、标志性色块、两个物体的关系、照片空间轮廓；
- **版画**：木刻、油毡版、丝网、单版画、粗颗粒孔版；
- **缺陷**：纸纤维吸墨、轻微错版、局部未着墨、压印凹痕、干刷断裂；
- **文字**：完整原文使用角落或边缘的小宋体、窄体无衬线或活字，可分为多行；非完整文字命题使用 2-8 字短标题；
- **情绪**：炽热荒诞、安静后果、温柔失去、冷幽默、克制哀伤、明亮异样、日常不安。

### 色彩控制

- 第一主墨色承担识别核心或魔法动作，占画面 20%-45%；
- 第二主墨色承担结构、环境或后果，占画面 5%-25%；
- 两种墨色合计占画面 30%-60%，纸张可见面积保持 30%-55%；
- 第三颜色仅在用户明确需要时作为小于 3% 的信号色；
- 颗粒、错版和干刷保持主墨色的饱和度与轮廓。

固定配色：墨绿+朱红、钴蓝+朱红、柠黄+深紫、群青+橙红、炭黑+荧光粉、深棕+酸绿；从中选择与用户输入最适配的一组，每组搭配自然纸色。

连续创作时，在适配性相同的候选之间轮换构图、魔法规则和配色。

本步输出一张配方卡：

```text
构图 / 锚点 / 版画+缺陷 / 两色+纸色 / 展示文字 / 情绪
```

## 4. Prompt 编译

输入为创作契约、视觉命题和配方卡。本步只负责精确编译，不增加创意。

### 编译字段

按顺序填写十个字段：

1. **Canvas**：3:4、纸张、平面扫描；
2. **Attention**：视觉重心、动作方向、主体与留白比例；
3. **Recognition**：观众通过什么特征认出输入；
4. **Magic Rule**：唯一的不可能因果关系；
5. **Transition**：变化前、边界、变化后和方向；
6. **Form**：剪影、局部、粗线、刀痕、平涂或负形；
7. **Typography**：完整原文或短标题、字体、位置、大小和分行方式；
8. **Color**：两种墨色的名称、职责和比例；
9. **Texture**：印刷工艺、辅助缺陷和纸张吸墨；
10. **Mood**：第一眼感受与理解规则后的余味。

### 四段式 Prompt

```text
第1段｜画布与构图
竖版3:4；[纸张]铺满画面；[构图]；视觉重心位于[位置]；主体朝[方向]运动；核心动作占[比例]，纸张可见[比例]。

第2段｜识别与变化
[识别令牌的典型特征]；唯一魔法规则是[规则]；变化前为[状态]，在[边界]发生变化，变化后成为[结果]。

第3段｜版画与文字
[印刷工艺]+[辅助缺陷]；只使用[墨色1]和[墨色2]，分别承担[功能]并占[比例]；把“[展示文字全文]”逐字完整呈现一次，使用[字体、位置、字号与分行]；画面没有其他文字。

第4段｜观看效果
第一眼感受[视觉钩子]，第二眼理解[输入联系]，随后留下[情绪余味]；保持平面印刷、清晰正负形、哑光吸墨和独立艺术海报完成度。
```

Prompt 必须说明主体在哪里、朝哪个方向运动、改变了什么、变化边界在哪里、留下什么结果。评分、分析和检查表保留在 Prompt 之外。

本步输出可直接用于生图的最终 Prompt。

## 5. 生成与修复

默认使用内置图像生成能力生成图片；用户明确只需要 Prompt 时，交付第 4 步结果。

### 双尺度检查

- 3:4 画布、主体、留白和两色比例符合契约；
- 三秒内能够通过识别令牌关联输入；
- 画面只运行一条魔法规则；
- 变化前后、边界和方向清楚；
- 缩略图具有明确轮廓、主色块和正负形；
- 平面印刷、纸张吸墨和辅助缺陷形成稳定版画身份；
- 完整文字命题逐字、完整、仅呈现一次；其他输入只呈现一个准确短标题；
- 作品能够经历“一秒吸引、三秒认出、十秒回味”。

### 单点重试

| 失败维度 | 只修改这一项 |
|---|---|
| 识别偏弱 | 放大锚点，补充一个典型细节 |
| 规则不清 | 强化变化前后、方向和边界 |
| 缩略图偏弱 | 扩大主色块或增强正负形 |
| 颜色漂移 | 重申只使用指定两种墨色与纸色 |
| 版画偏弱 | 强化平涂、刀痕、吸墨和错版 |
| 画面过密 | 保留主关系，减少辅助标记 |
| 文字失真 | 保持原文完整，扩大文字区域，调整字号和分行，明确逐字内容与出现次数 |

保持其他配方不变，只再生成一次。
